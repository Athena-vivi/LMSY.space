## 实现上要定的两件事

1. **Tab 的取值**：`drama_work` 现在没有 subtype。要加三个值（`affair` / `harmony_secret` / `hometown_romance`）并配三语文案，以后上新剧就加一个值，Tab 自动多一个（沿用现有 `subtypeTabs()`：有内容才出现）。
2. **详情页 URL**：剧详情建议 `/dramas/[slug]`（每部独立可收录），不放进 `/projects/[id]`。这样 L1、L2、L3 三层各自有干净 URL，SEO 才落得实。
